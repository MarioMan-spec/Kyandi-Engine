# Kyandi-Engine
Kyandi is a Open Source game engine Designed Using DirectX to make Immersive 3D Games and script them In  KyandiScript a Lua Like scripting Language or in Python. this Game Engine is designed for Making Enhanced 3D Games for Windows Platform you can edit your Game in a GUI Based Editor just Like Unity oe Unreal Engine. fun fact: Kyandi Is the Japanese word for Candy
